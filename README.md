# Yash Goel — portfolio

Personal site: a maroon chalkboard photo board, projects that open on click, a scroll-walked journey map, and a painted-sky contact section.

Built with React + Vite. All copy lives in `src/content.js`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
